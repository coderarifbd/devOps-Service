# DevOps Landing Page | Advanced Operations Technology (AOT)

A premium, modern, responsive corporate landing page for DevOps Managed Services & Consulting, built using AOT's brand style guides (light mode base with crimson red accents) and featuring custom high-resolution isometric diagrams.

## Key Features
- **Header & Navigation**: Glassmorphic sticky header containing active navigation links and mobile responsive toggle menu.
- **Hero Section**: 2-column desktop layout featuring badges, left-aligned typography content, and a custom high-resolution DevOps infrastructure diagram.
- **Stats Panel**: Floating card panel straddling the border between the hero and features sections.
- **Why Choose Us**: Responsive 3-column card grid with custom inline SVGs and active red border hover transitions.
- **Our Services**: Tabbed breakdown selector toggling between Managed DevOps and Consulting Strategy.
- **Partnership**: Split section pairing DevOps collaboration illustrations with checkmarked value statements.
- **Contact Form**: Request form validation with emerald success toast alert banner.
- **Footer**: Corporate dark slate design.

## Tech Stack
- **HTML5** (semantic markup structure)
- **CSS3** (responsive layout grids, variables, and keyframe floating animation paths)
- **JavaScript** (ES6 Vanilla JS DOM toggling and scroll event handlers)

## Getting Started
Open `index.html` directly in your browser or start a local HTTP server:
```bash
python -m http.server 8000
```
Then visit: `http://localhost:8000`
